## 🎨 Visual Design Elements

### Color Scheme
- **Primary Navy:** #002546 (headers, main text, CTA buttons)
- **Secondary Cream:** #F5EFE0 (backgrounds, highlights)
- **Accent Orange:** #D97706 (links, category badges, hover states)
- **Surface White:** #FFFFFF (main content area)
- **Text Dark:** #1F2937 (body text)
- **Border Light:** #E5E7EB (section dividers)

### Typography
- **Headlines:** Merriweather (serif) - 30-36px
- **Section Titles:** Merriweather (serif) - 24-28px
- **Card Titles:** Merriweather (serif) - 18-22px
- **Body Text:** Inter (sans-serif) - 15-17px
- **Small Text:** Inter (sans-serif) - 13-14px

### Component Styles
- **Buttons:** Rounded corners, shadow on hover, clear CTA
- **Cards:** Light background, subtle border, consistent spacing
- **Navigation:** Dropdown menus, sticky header, responsive hamburger
- **Links:** Orange accent color, underline on hover
- **Icons:** Material Symbols Outlined for consistency

### Spacing & Layout
- **Sections:** 56px padding (vertical)
- **Content Areas:** Max-width 1280px (container)
- **Grid:** 3-column for desktop, 2-column for tablet, 1-column for mobile
- **Gap:** 24px between grid items

## 📐 Responsive Breakpoints

### Desktop (1920px and above)
```
Navigation: Horizontal menu with dropdowns
Quick Links: 4 columns × 2 rows
Departments: 3-column grid (with featured 2-column card)
Hero: Full-width video with centered text
```

### Laptop (1280-1920px)
```
Navigation: Full horizontal menu
Quick Links: 4 columns × 2 rows
Departments: 3-column grid
Hero: Full-width optimized
```

### Tablet (768-1280px)
```
Navigation: Dropdown menu, hamburger available
Quick Links: 2 columns × 4 rows
Departments: 2-column grid
Hero: Video background, text center-aligned
```

### Mobile (320-768px)
```
Navigation: Hamburger menu (stacked)
Quick Links: 2 columns × 4 rows
Departments: 1 column (featured card full width)
Hero: Video background, text optimized for small screens
```
