## 🎓 Academic Programs

1. **Diploma in Printing Technology**
   - Duration: 3 years (6 semesters)
   - Intake: 60 seats/year
   - SBTE Code: Printing
   - Specializations: Offset, Flexo, Gravure, Packaging, Digital

2. **Diploma in Computer Engineering**
   - Duration: 3 years (6 semesters)
   - Intake: 60 seats/year
   - SBTE Code: 104
   - Focus: Algorithms, Web Tech, Databases, Cloud

3. **Diploma in Electronics Engineering**
   - Duration: 3 years (6 semesters)
   - Intake: 60 seats/year
   - SBTE Code: 103
   - Focus: Digital Electronics, IoT, Automation, Telecom

4. **General & Applied Sciences**
   - Semesters 1-2 Foundation courses
   - Common for all diploma programs
